# Map360 — Collaborative 3D World Mapping Platform

A social, collaborative platform where users progressively build a shared 3D
world by scanning real-world storefronts and landmarks. Each private group keeps
its own isolated version of the world map, evolving in real time as members
contribute.

See [`project details/outline.MD`](project%20details/outline.MD) for the product
vision and [`project details/checklist.MD`](project%20details/checklist.MD) for
the build roadmap.

## Tech Stack

| Area          | Choice                                                        |
| ------------- | ------------------------------------------------------------- |
| Backend       | FastAPI (async) + SQLAlchemy 2.0 + Alembic                    |
| Database      | Supabase Postgres (accessed via `asyncpg`)                    |
| Media storage | Supabase Storage (used later in the roadmap)                  |
| Auth          | Application-owned JWT auth (not Supabase Auth)                |
| Frontend      | Vite + React + TypeScript, installable **PWA**                |
| 3D rendering  | Three.js via React Three Fiber (`@react-three/fiber`, `drei`) |

> Supabase is used for hosted Postgres and object storage only. Authentication
> is handled by this application.

## Prerequisites

- Python 3.12+
- Node.js 20+
- A Supabase project (for the Postgres connection string and Storage)

## Backend Setup

```bash
cd backend

# Create and activate a virtual environment
python -m venv .venv
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# macOS / Linux
# source .venv/bin/activate

pip install -r requirements.txt

# Configure environment
copy .env.example .env      # Windows
# cp .env.example .env       # macOS / Linux
# then edit .env with your Supabase values
```

Required environment variables (see [`backend/.env.example`](backend/.env.example)):

- `DATABASE_URL` — Supabase Postgres URL using the async driver, e.g.
  `postgresql+asyncpg://postgres:<password>@db.<ref>.supabase.co:5432/postgres`
- `JWT_SECRET_KEY` — a long random secret for signing app-issued tokens
- `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `SUPABASE_MEDIA_BUCKET` — for
  media storage (used later)

### Database Migrations (Alembic)

```bash
cd backend

# Apply migrations to the configured database
alembic upgrade head

# Create a new migration after changing models
alembic revision --autogenerate -m "describe change"
```

### Run the API

```bash
cd backend
uvicorn app.main:app --reload
```

The API runs at http://127.0.0.1:8000 (docs at `/docs`).

## Frontend Setup

```bash
cd frontend
npm install

# Development server (PWA enabled in dev)
npm run dev

# Production build + preview
npm run build
npm run preview
```

The dev server runs at http://127.0.0.1:5173.

### PWA Notes

The frontend is an installable Progressive Web App via `vite-plugin-pwa`:

- Web app manifest and icons are configured in
  [`frontend/vite.config.ts`](frontend/vite.config.ts) and
  [`frontend/public/`](frontend/public).
- A service worker is generated on build (`dist/sw.js`) and registered in
  [`frontend/src/main.tsx`](frontend/src/main.tsx).
- Placeholder icons are generated by
  [`frontend/scripts/gen_icons.py`](frontend/scripts/gen_icons.py); replace them
  with branded artwork before production.
